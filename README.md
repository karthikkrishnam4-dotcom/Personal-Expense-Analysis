# Personal Expense Analysis

A data analysis project to understand personal spending patterns using Python, SQL, Pandas, NumPy, Matplotlib and Seaborn.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL

## Dataset

The dataset contains personal expense records with:

- Expense ID
- Date
- Category
- Description
- Amount
- Payment Method

## Analysis Performed

### SQL Analysis

- Total spending by category
- Average spending by payment method
- Highest expense in each category
- Expenses above the overall average
- Top 3 highest expenses
- Monthly spending and transaction count
- GROUP BY and HAVING
- Subqueries
- CTEs
- Window functions
- Date functions

### Python Analysis

- Dataset inspection
- Missing value checking
- Basic statistics
- Category-wise spending
- Payment method analysis
- Monthly spending
- Top and lowest expenses
- Daily spending analysis

## Visualizations

Created visualizations using Matplotlib and Seaborn:

- Spending by Category
- Monthly Spending Trend
- Spending by Payment Method
- Expense Distribution
- Expense Distribution and Outliers
- Correlation Heatmap

## Key Insights

- Total spending: ₹9,489
- Average expense: ₹395.38
- Highest spending category: Shopping
- Highest spending payment method: Card
- Highest spending month: January 2026
- Highest individual expense: Shoes — ₹1,800
